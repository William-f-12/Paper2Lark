# M6 release implementation plan

> **For agentic workers:** Use superpowers:subagent-driven-development to implement and review these tasks.

**Goal:** Deliver reproducible public distribution artifacts, actionable installation/upgrade instructions, and an honest release evidence report.

**Architecture:** Keep the existing dependency-free zipapp and two local marketplaces. Add a separate deterministic archive builder and offline archive checks; persistent private homes remain external. Host validation uses isolated host configuration directories and extracted release artifacts.

**Tech Stack:** Python 3.11+ standard library, existing lark-cli, Claude Code/Codex plugin commands, GitHub Actions.

**Spec:** docs/superpowers/specs/2026-09-13-paper2lark-design.md sections 16.3 and 18.

## Global constraints

- No added runtime dependencies; retain the stronger 262144-byte per-plugin budget.
- English distributable documentation; English/Chinese library support unchanged.
- No personal account data or credentials in artifacts or public fixtures.
- No production Lark writes or authentication resets for release testing.
- Version 0.7.0; unchanged SQLite schema v3. Preserve old artifacts for pinned unfinished runs.
- Public release certification requires real host and remote workflow evidence. Missing evidence is explicitly pending, never inferred from synthetic tests.
- Build artifacts locally; no automatic GitHub publication or existing plugin replacement.
